# Project knowledge base

The canonical knowledge about `robinreinecke.de` lives here. Each file covers one concern so it
can be found and kept current independently. [AGENTS.md](../AGENTS.md) is only a starting point —
the details live below.

**Keep these docs current.** Every change that affects how the code works, is built, or is
operated must update the relevant file here in the same change. Out-of-date docs are treated as a
bug.
